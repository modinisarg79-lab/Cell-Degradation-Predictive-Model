# 🔋 NMC Cell Degradation Predictive Model

### 📌 The Business Problem
In high-volume NMC cell manufacturing, manual end-of-line testing relies on immediate OCV/IR limits but cannot predict long-term capacity degradation. This reactive approach leads to high warranty failures and undetected scrap. 

### 🔬 The Solution
Developed a Machine Learning predictive model using NASA's Li-ion aging dataset. By analyzing charge-discharge cycles, voltage drops, and thermal drifts, this model estimates the State of Health (SOH) and Remaining Useful Life (RUL) of individual cells before they fail.

### 🛠️ Tech Stack & Methodology
* **Domain Focus:** NMC Cell Chemistry, Charge-Discharge Characterization, Cycle Life Aging
* **Data Stack:** Python, Pandas, NumPy, Scikit-Learn (Random Forest Regressor), Matplotlib
* **Dataset:** NASA Prognostics Center of Excellence (PCoE) Battery Dataset
